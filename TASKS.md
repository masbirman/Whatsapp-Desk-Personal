# Daftar Tugas — WhatsApp Desk Personal

Dokumen ini adalah daftar pekerjaan yang direncanakan; isinya tidak memberi izin untuk melewati titik berhenti antar-milestone. Status tugas: `DIRANCANG`, `SEDANG DIKERJAKAN`, `SELESAI`, `TERHAMBAT`, atau `DITUNDA`. M1–M3 selesai. M4 selesai: kebijakan notifikasi Go dengan redaksi terkunci, driver Windows/Linux, overlay taskbar numerik, tray Windows, dbusmenu Linux (terverifikasi runtime via DBus), lock-on-tray, dan UI settings tray. Verifikasi runtime penuh hanya pada Ubuntu; Windows tetap build/vet/statik saja (tanpa sesi Windows). M5–M7 tetap `DIRANCANG`. Pekerjaan berhenti pada checkpoint M4 sampai ada instruksi berikutnya.

Nama file, modul, API, dan istilah teknis tertentu dipertahankan dalam bahasa aslinya agar mudah dicocokkan dengan source code.
